The site contains policy pages and the advertising seller declaration only.

For GitHub Pages, publish the repository root. Use a repository named USERNAME.github.io to serve app-ads.txt at the domain root, unless an existing root site or custom domain already serves it. A project site at USERNAME.github.io/REPOSITORY/ needs app-ads.txt separately at USERNAME.github.io/app-ads.txt or the selected developer domain root.

Before entering a URL in Google Play or AdMob, verify the deployed HTTPS pages are publicly accessible without sign-in. The GitHub repository URL is not the hosted privacy-policy URL.
